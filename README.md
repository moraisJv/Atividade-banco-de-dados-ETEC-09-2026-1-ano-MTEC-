# 🗄️ Technical Activity: Data Manipulation and Querying in SQL

This repository contains the solution to a database practical activity developed during the **Internet Computing** course at **ETEC Uirapuru**, under the guidance of Prof. Cleiton Dias.

The goal of the project was to apply the concepts of **DML (Data Manipulation Language)** and **DQL (Data Query Language)** in the **MySQL** database to solve real-world scenarios and problems, without using foreign keys or relationships in this initial stage.

##  Technologies Used
* **MySQL** (Database structuring and queries)
* **GitHub** (Portfolio hosting and version control)

## Real-World Scenarios Solved

The project was divided into 7 different client stories, where each `.sql` file provides a practical approach to creating tables, inserting sample data, updating data (`UPDATE`), deleting data (`DELETE`), modifying table structures (`ALTER TABLE`), and applying advanced filters:

1. **Mr. Antônio’s Grocery Store (`01_mercadinho_antonio.sql`)**
   * Grocery store inventory management, price adjustments, adding new brand columns, and product quantity filters.
2. **Alpha Technology HR Department (`02_rh_alpha_tecnologia.sql`)**
   * Migration of spreadsheets to a database, employee promotions with salary adjustments, changing field sizes, and salary range filters.
3. **Saber Library (`03_biblioteca_saber.sql`)**
   * Digitization of the book collection, adding donated copies to the current inventory, correcting categories, and listing available titles.
4. **Estilo Jovem Store (`04_loja_estilo_jovem.sql`)**
   * Replacement of paper index cards with clothing catalogs, recording of sales, inventory control by model, and searches based on price and availability.
5. **Vida Nova Hospital (`05_hospital_vida_nova.sql`)**
   * Simple patient registration, updates to address and city information, removal of duplicate records, and geographic location filters.
6. **Carlos’s Auto Shop (`06_oficina_carlos.sql`)**
   * Management of serviced vehicles, incremental mileage updates
